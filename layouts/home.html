Wegweiser

An authoritative DNS server with a web interface you don't need a manual for.

Get started Source Releases

Reverse zones manage themselves

An address record produces the matching PTR in the zone responsible for it, IPv6 nibble zones and RFC 2317 delegation included. A conflict is shown, never silently overwritten.

Every change is reversible

Each edit is a journal event, so zone history, a diff of any change, an audit trail and rollback to an earlier state all come out of one mechanism.

Two clients, one API

A keyboard-driven web interface with a live query stream, and a command line that reaches everything it does. Neither touches the database.
